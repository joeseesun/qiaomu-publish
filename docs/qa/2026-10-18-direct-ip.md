# Direct-mode public IP assistance — 0.3.2

## Behavior

Both account settings and first-time publishing now offer an on-demand IPv4 query and copy action. The HTTPS ipify query sends no account credentials or article data. Its result is explicitly approximate when proxies route WeChat differently. A typed WeChat 40164 error replaces the lookup result with the address observed by WeChat. Results stay in memory and are cleared when switching connection modes; late lookups cannot overwrite a newer WeChat error or a closed form.

## Verification

- Regression coverage: credential-free requests; public IPv4 validation; HTTP failures; 10-second deadline; WeChat error extraction without leaked server text; duplicate clicks; copying only the IP; clipboard failure; mode changes/closing during a request; WeChat responses taking priority over a late lookup.
- The existing all-theme test intermittently exceeded its shared five-second deadline under local contention. It now runs the same assertions once per named theme, preserving the timeout and all themes. Test workers are capped at two to reduce contention.
- macOS Obsidian 1.14.4 isolated vault: installed 0.3.2, preserved existing settings, loaded fresh defaults, and verified both connection entry points with empty credentials. No account credentials were submitted and no WeChat drafts were created.
- A real ipify request succeeded through Obsidian's request API. The actual system clipboard received exactly the detected IP; the previous text clipboard was restored.
- Light/dark and 480px window checks: IP helper widths 506px / 350px, no horizontal overflow. The narrow form scrolls while footer buttons remain visible. A previously hidden save-without-test button now respects its hidden state. Native Shift+Tab focused the query button with a 1px neutral outline.
- Official Obsidian ESLint rules: zero errors. Advisory warnings retain the existing native-DOM/desktop-API guidance and sentence-case suggestions; new Chinese text retains conventional AppID, IPv4 and VPN spelling.

Local evidence: `/tmp/qiaomu-direct-ip-qa/`, including `native-result.json`, `final-install.json`, screenshots and lint JSON; full check log `/tmp/qiaomu-direct-ip-final-check.log`. These local paths contain QA artifacts, not runtime dependencies.

## Boundaries

IPv6 querying, mobile hardware, every VPN/proxy configuration, and actual account access after a user changes their WeChat allowlist are not verified. The interface makes the authoritative connection test explicit. Official preview, draft-asset verification, anonymous downloads, main-branch merge, formal review and native update are separate release gates, recorded in the PR/release after the final candidate is frozen.

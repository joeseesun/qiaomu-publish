## 0.3.2：直连时查询并复制公网 IP

- 选择「当前设备直连」后，可在设置和首次连接窗口查询公网 IPv4，一键复制到公众号后台的 API IP 白名单。
- 测试连接遇到白名单错误时，优先显示微信返回的出口 IP；换网络或切换 VPN 后可重新查询。
- 查询仅在点击时访问 ipify，不发送公众号凭据或文章。查询失败仍可测试公众号连接。
- 调整窄窗口的表单滚动，保留完整的底部操作按钮。

已在 macOS Obsidian 验证公网查询、系统剪贴板、两处连接入口和浅深色／窄窗口显示。代理分流时查询结果仅供参考，以微信返回的地址和连接测试为准；IPv6 查询、手机真机和用户填写白名单后的真实公众号操作未验收。

在 Obsidian「设置 → 第三方插件 → 检查更新」升级。手动安装下载同版本的 `main.js`、`manifest.json`、`styles.css`，保留 `data.json`。

### English

- Accept source images and covers up to 50 MiB, with automatic compression before upload.
- Reduce image dimensions when JPEG quality changes alone cannot meet upload limits.
- Identify failed images and explain server upload size limits.

GIF upload limits remain transport-specific. Original attachments stay unchanged. Live relay checks and release validation are recorded in the QA report; physical mobile devices are not covered.
